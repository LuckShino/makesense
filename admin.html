LOCAL SAVE

この端末への保存・データ出力

編集はこのブラウザに一時保存されます。同じURLで開いたゲームにはページ再読み込み後に反映されます。ローカルファイル（file://）ではブラウザにより保存領域が分かれるため、下の「データファイルをダウンロード」を利用してください。

JS版はサイト内の data/admin-data.js と入れ替えると、公開データとして反映できます。変更前にバックアップを取ってください。

CROSS-DEVICE PUBLISH

GitHubでスマホ・PCの変更を共有

サイトをGitHub Pagesに公開した後、以下を設定すると「GitHubに公開」から両端末共通の data/admin-data.js を更新できます。反映まで数分かかる場合があります。

トークンはこの画面を開いている間だけ保持し、ファイル・公開データ・ブラウザの保存領域には記録しません。GitHubで対象リポジトリの Contents: Read and write のみを許可してください。管理画面のURL自体は秘密の認証にはなりません。

GitHubを使う場合に設定してください。
